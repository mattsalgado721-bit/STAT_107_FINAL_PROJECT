# STAT_107_FINAL_PROJECT

## Files
* 00_requiremnts.R - contains the necessary packages to run this project.
* 01_funct_DataCleaning.R - contains functions necessary for data cleaning.
* 11_DataCleaning.Rmd - contains the code used to clean the data.
* 12_DataSaving.RData - contains the cleaned dataset and used to load it into the current environment.
* 21_DataVisualization - contains data analysis and visualization of the data.

## Usage
1. Clone the repository into a folder.
2. Open and run 00_requirment.R
3. Open 11_DataCleaning.Rmd and run all chunks.
4. Open 21_DataVisualization.Rmd and run all chunks
